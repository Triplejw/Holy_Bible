# 📖 Holy Bible App (Expo Go)

A fully responsive Holy Bible app developed using React Native and Expo Go. The app runs seamlessly across Android, iOS, and the web — offering scripture reading, clean UI, and offline support.

## ✨ Features
- 🕊️ Read the full Bible (Old & New Testament)
- 🔍 Search and navigate through books, chapters, and verses
- 🌙 Dark/Light mode support
- 📲 Works on Android, iOS, and Web via Expo
- 📶 Offline-ready architecture (optional if implemented)
